# Busy Beaver 6 Holdouts (`BusyBeaver/BB6/`)

This directory formalizes **323 distinct `BB(6)` (6-state, 2-symbol) Turing machines**: **`109`** behavioral reductions and potential cryptids organized by dynamical family in **[`BusyBeaver/BB6/Accelerations/`](./Accelerations/README.md)**, together with **`214`** resolved single-file proofs in **[`BusyBeaver/BB6/Halt/`](./Halt/)** (`35` `IsHalt`) and **[`BusyBeaver/BB6/NonHalt/`](./NonHalt/)** (`179` `IsNotHalt`, including [A6](../../artifacts/a6/README.md) and [*Pomme*](./NonHalt/M_1RB1LA_1RC1RE_1LD0RB_1LA0LC_0RF0RD_0RBHHH.lean), which also carries its Level A/B counter reduction). Resolved holdouts whose halting or non-halting proofs span multiple files (such as `#413`, `#748`, and `#749`) are omitted for size.

## Resolved `BB(6)` Machines

This directory formalizes 214 resolved `BB(6)` Turing machines (`35` halting + `179` non-halting, including [A6](../../artifacts/a6/README.md) and *Pomme*) reproducing community proofs and `busycoq` results directly verified in Lean 4 without axioms (`sorry`-free and `native_decide`-free kernel verification):

- **[`BusyBeaver/BB6/Halt/`](./Halt/)**: 35 resolved halting machines (`IsHalt`), each reaching a halting configuration from `init []` with verified multi-step traces.
- **[`BusyBeaver/BB6/NonHalt/`](./NonHalt/)**: 179 resolved non-halting machines (`IsNotHalt`, including [A6](./NonHalt/M_1RB0LF_1RC0RA_1LD0RB_0LE0LC_0LA0LC_0LBHHH.lean) and [*Pomme*](./NonHalt/M_1RB1LA_1RC1RE_1LD0RB_1LA0LC_0RF0RD_0RBHHH.lean)), verified via inductive invariants, simulated cycles, or closed-set reachability certificates.

### [Pomme (`1RB1LA_1RC1RE_1LD0RB_1LA0LC_0RF0RD_0RB---`) High-Level Acceleration](./NonHalt/M_1RB1LA_1RC1RE_1LD0RB_1LA0LC_0RF0RD_0RBHHH.lean)

Contracting the diagonal sweep $P_{270}(a + 2, b, c + 4) \to P_{270}(a, b + 3, c)$ via $k = \min(\lfloor a/2 \rfloor, \lfloor c/4 \rfloor)$ and draining any intermediate $P_{61}(a', c')$ with $a' > 0$ (which decreases $c$ by at least $6$) reduces the *Pomme* / Baker machine to a **single-counter** map on $P(c) := P_{61}(0, c) = 0^\infty \ 1 \ \mathrm{B}{>} \ 1^{c+3} \ 01 \ 0^\infty$, starting from $P(7)$:

$$
T(P(c)) = D(0, c),
$$

where `drainP` ($D(a, c)$) is defined recursively on $c$ (writing $c_0 = c - 3$, $k = \min(\lfloor a/2 \rfloor, \lfloor c_0/4 \rfloor)$, $a_1 = a - 2k$, $b_1 = 3k$, and $c_1 = c_0 - 4k$ when $c \ge 3$):

$$
D(a, c) = \begin{cases}
  P(4a + 4\lfloor a/2 \rfloor + 15) & \text{if } c = 0, \\
  P(2a + 11) & \text{if } c = 1, \\
  \text{Halt} & \text{if } c = 2, \text{ or } (c \ge 3,\ c_1 \le 1,\ a_1 < 2), \text{ or } (c \ge 3,\ c_1 = 3,\ a_1 \ge 2), \\
  P\bigl(4(a_1 - 2) + 4\lfloor (a_1 - 2)/2 \rfloor + 4b_1 + 35 - 8c_1\bigr) & \text{if } c \ge 3,\ c_1 \in \lbrace 0, 1 \rbrace,\text{ and } a_1 \ge 2, \\
  P(2a_1 + 2b_1 + 13) & \text{if } c \ge 3 \text{ and } c_1 = 2, \\
  P(12b_1 + 63 + 12a_1) & \text{if } c \ge 3,\ c_1 = 3,\text{ and } a_1 \in \lbrace 0, 1 \rbrace, \\
  D(2b_1 + 8 + 2a_1,\ c_1 - 3) & \text{if } c \ge 3 \text{ and } c_1 \ge 4 \text{ (here } a_1 \in \lbrace 0, 1 \rbrace\text{)}.
\end{cases}
$$
